# Здесь было…

*Великий Новгород сквозь время*

Мобильный гид по Великому Новгороду. Вы гуляете по городу, а когда проходите мимо
исторического места, приходит уведомление. В нём старое фото, эпоха и короткий рассказ
о том, что здесь было раньше.

Стек: **Flutter** + **flutter_map** (тайлы MapTiler / OpenStreetMap) + **geolocator** +
**flutter_local_notifications**.

Карта: © MapTiler © OpenStreetMap contributors.

## Установка

Готовые файлы лежат в [Releases](https://github.com/prop1l/novgorod-hackathon/releases/latest).

- **Android:** скачайте `zdes-bylo-<версия>-arm64.apk` на телефон и откройте. Он подходит почти всем
  телефонам последних лет. Для совсем старых телефонов есть `-armv7.apk`. Если система спросит,
  разрешите установку из этого источника.
- **iOS:** `zdes-bylo-<версия>-ios-unsigned.ipa` не подписан, потому что для этого нужен платный
  аккаунт Apple Developer. Поставить его можно через [AltStore](https://altstore.io) или
  [Sideloadly](https://sideloadly.io) с вашим Apple ID. С бесплатным Apple ID приложение
  работает 7 дней, потом его нужно переустановить.

## Возможности

- Карта с 21 историческим местом: Детинец, София, Ярославово дворище, Юрьев и Десятинный монастыри и др.
- Иконки по категориям (храм, крепость, площадь, монастырь…), посещённые места отмечены зелёным
- Своя геопозиция и кнопка «где я»
- Фоновый гид: Android foreground service «Гид активен», `distanceFilter` 25 м
- Уведомление о месте рядом: кулдаун 12 ч на место, не чаще 1 раза в 2 минуты
- Тап по уведомлению открывает карточку места, в том числе если приложение было закрыто
- Карточка: слайдер «тогда / сейчас», «как появилось», «что тут было», «что тут делали», маршрут
- **Разбор снимка**: номера на старом и новом фото — что сохранилось, что перестроено, что утрачено (все 21 место, 60 деталей)
- **Прогулки**: маршруты по точкам «Торговая сторона, 1880–1910 годы», «Детинец сквозь время», «Софийская сторона: чего больше нет» — линия на карте, следующая точка, прогресс; демо-прогулка идёт по выбранному маршруту
- Список мест по расстоянию с отметкой «посещено»
- **Достижения**: 10 значков за посещённые места («Знаток Детинца», «Паломник», «Хранитель истории»…), прогресс по каждому, уведомление и карточка при получении
- Настройки: гид вкл/выкл, радиус срабатывания, сброс прогресса
- **Демо-прогулка**: позиция сама идёт по центру от Кокуя до Ильиной улицы, и приходят настоящие уведомления
- Понятные экраны вместо краша, если геолокация выключена или не разрешена
- Офлайн-данные: тексты и фото лежат в `assets/`

## Запуск

Ключ MapTiler лежит в `env.json`. Файл в `.gitignore` и в репозиторий не попадает.
Чтобы создать его у себя, скопируйте `env.example.json` в `env.json` и вставьте ключ.

```bash
flutter pub get
flutter run --dart-define-from-file=env.json
```

Без ключа карта берёт тайлы OpenStreetMap. Так можно только при разработке:
правила tile.openstreetmap.org не разрешают использовать их в продакшене.

В кабинете MapTiler ограничьте ключ по id приложения: Android `ru.novgorod.skvoz_vremya`,
iOS `ru.novgorod.skvozvremya` (в iOS подчёркивания запрещены).

> ⚠️ Если в пути к проекту есть кириллица (например, `~/Документы/...`), Flutter 3.47
> падает в `flutter analyze` с `FormatException: Unexpected end of input`. Держите проект
> в папке с латинским путём, например `~/projects/novgorod-hackathon`.

### Release APK

```bash
flutter build apk --release --split-per-abi --target-platform android-arm,android-arm64 --dart-define-from-file=env.json
```

Получатся два APK по ~25 МБ в `build/app/outputs/flutter-apk/`: `app-arm64-v8a-release.apk`
(почти все телефоны) и `app-armeabi-v7a-release.apk` (старые). Один общий APK весил бы ~63 МБ: в нём
лежат копии движка под все процессоры.

Релиз подписывается ключом `android/app/release-keystore.jks`, пароли лежат в
`android/key.properties`. Оба файла в `.gitignore`: они есть только у того, кто выпускает
релизы. Без них сборка подписывается debug-ключом. Если ключ потерять, обновить уже
установленное приложение не получится, поэтому храните копию в надёжном месте.

### Выпуск релиза

1. Поднимите `version` в `pubspec.yaml`.
2. Соберите подписанный APK командой выше.
3. Создайте релиз с обоими APK: `gh release create v1.2.0 zdes-bylo-1.2.0-arm64.apk zdes-bylo-1.2.0-armv7.apk`.
4. Workflow [release-ios.yml](.github/workflows/release-ios.yml) сам соберёт iOS `.ipa` на macOS
   и приложит его к релизу. Ключ карты он берёт из секрета репозитория `MAPTILER_KEY`.

### iOS

На каждый push в `main` GitHub Actions собирает iOS-версию без подписи на macOS
([.github/workflows/ios.yml](.github/workflows/ios.yml)), так что видно, компилируется ли она.
Чтобы поставить приложение на iPhone, нужен Mac с Xcode:

```bash
flutter run --release --dart-define-from-file=env.json
```

С бесплатным Apple ID приложение работает 7 дней, для TestFlight нужен платный аккаунт разработчика.

### Тесты

```bash
flutter test
```

Тесты проверяют haversine, антиспам и кулдауны `ProximityChecker`, а также корректность `places.json`.

## Структура

```
assets/data/places.json      каталог мест
assets/data/demo_track.json  трек демо-прогулки
assets/data/walks.json       прогулки: порядок точек маршрута
assets/photos/               фото «тогда» и «сейчас» в WebP
lib/models/place.dart        модель места и категории
lib/models/achievement.dart  достижения и подсчёт прогресса
lib/services/geo.dart        haversine, разбиение трека
lib/services/proximity_checker.dart  какое место ближе и можно ли уведомить
lib/services/location_service.dart   geolocator + фоновый режим
lib/services/notification_service.dart  уведомления, payload = id места
lib/services/storage.dart    посещённые места и настройки (shared_preferences)
lib/state/app_state.dart     общее состояние, демо-режим
lib/screens/                 онбординг, карта, карточка, список, настройки
```

## Формат `places.json`

| поле | смысл |
|---|---|
| `id` | уникальный id, он же payload уведомления |
| `name` | название |
| `lat`, `lon` | координаты (из OpenStreetMap) |
| `radius` | радиус срабатывания, м |
| `era` | эпоха или год |
| `category` | `temple`, `fortress`, `square`, `monastery`, `monument`, `bridge`, `museum` |
| `photo_old`, `photo_now` | пути к фото в assets (или `null`) |
| `photo_credit` | автор, лицензия и источник каждого фото |
| `short` | одна фраза для уведомления |
| `history` | «как появилось» |
| `what_happened` | «что тут было» |
| `activities` | «что тут делали» |
| `marks` | разбор снимка: `n`, `status` (`kept` / `changed` / `lost`), `title`, `text`, `old` и `now` — точка `[x, y]` в долях кадра |

Фото взяты с Wikimedia Commons. Старые снимки находятся в общественном достоянии, современные
распространяются по лицензиям CC BY / CC BY-SA, автор указан в `photo_credit` и на карточке места.

## Демо на защите

1. Настройки → «Демо-прогулка» или кнопка с пешеходом на карте.
2. Синяя точка идёт по центру. Возле каждого места приходит уведомление, во время демо
   примерно раз в 6 секунд.
3. Тап по уведомлению открывает карточку.

Запасной вариант: Mock Location в настройках разработчика Android.

## Если уведомления не приходят в фоне

Xiaomi, Huawei, Honor и Samsung агрессивно закрывают фоновые приложения. Откройте
Настройки → Приложения → «Здесь было…» → Батарея → «Без ограничений» и
разрешите автозапуск.
