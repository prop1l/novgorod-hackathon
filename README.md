# Здесь было…

Гид по Великому Новгороду. Гуляете по городу — телефон подсказывает, какое историческое место рядом,
и показывает старое фото: что здесь сохранилось, а что исчезло.

## Скачать

Последняя версия — на странице [Releases](https://github.com/prop1l/novgorod-hackathon/releases/latest).

**Android** — скачайте APK на телефон и откройте его:

- `…-arm64.apk` — **почти все телефоны** (если не знаете, какой — берите этот);
- `…-armv7.apk` — старые телефоны, если первый не установился.

**iPhone** — файл `…-ios-unsigned.ipa`. Его ставят через [AltStore](https://altstore.io) или
[Sideloadly](https://sideloadly.io) со своим Apple ID (с бесплатным приложение работает 7 дней).

## Что умеет

- Карта с 21 историческим местом
- Старое и новое фото места рядом — и номера: что сохранилось, перестроено, утрачено
- Три прогулки по точкам со старыми снимками
- Уведомление, когда вы рядом с местом
- Достижения за посещённые места
- **Демо-прогулка** — кнопка с пешеходом на карте: точка сама идёт по маршруту

## Для разработчиков

Нужен Flutter. Ключ карты MapTiler положите в `env.json` (образец — `env.example.json`).

```bash
flutter run --dart-define-from-file=env.json
```

Сборка APK для релиза:

```bash
flutter build apk --release --split-per-abi --target-platform android-arm,android-arm64 --dart-define-from-file=env.json
```
